# الرافدين تيك

واجهة أولية لتطبيق فيديوهات قصيرة باللغة العربية، مبنية باستخدام React وVite.

## تشغيل المشروع
```bash
npm install
cp .env.example .env
npm run dev
```

## تفعيل الحسابات والفيديوهات والتعليقات

1. أنشئ مشروعاً في [Supabase](https://supabase.com/).
2. من Project Settings ثم API انسخ Project URL و anon/public key إلى ملف `.env`.
3. افتح SQL Editor وشغّل كامل محتوى `supabase/schema.sql`.
4. أعد تشغيل Vite. لا تضع service_role key في تطبيق المتصفح أبداً.

خدمات الخلفية موجودة في `src/services/videoService.js`: إنشاء حساب، تسجيل دخول، رفع فيديو، جلب التغذية، التعليقات والإعجابات. الواجهة الحالية تبقى بوضع العرض التجريبي إلى أن تُضاف مفاتيح Supabase وتُربط مكونات الواجهة بهذه الخدمات.

## حدود الرفع الحالية
- فيديو MP4 أو WebM أو MOV.
- الحد الأقصى 100MB.
- التخزين العام مخصص لمقاطع الفيديو المنشورة؛ راجع سياسات RLS قبل النشر العام.

## أوامر
- `npm run dev` تشغيل محلي
- `npm run build` بناء نسخة الإنتاج
